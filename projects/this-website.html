This website

Personal project · 2026

A personal site in plain HTML, CSS and JavaScript, built with Claude Code and animated with GSAP.

How it’s built

Every page is a plain HTML file with one shared stylesheet and a few small scripts. There’s no framework and no build step, and it’s hosted on GitHub Pages. I built it with Claude Code.

GSAP and its ScrollTrigger plugin run the motion: the intro on the home page, the dive into Work as you scroll, the rows that rise into view and the numbers that count up.

The water

The background is drawn on a canvas: a field of grey dots that flows like the surface of a pool, and a small school of violet fish. Move a cursor or a finger through it and the dots part while the fish swim away.

It’s a nod to swimming: I swam for NYU from 2023 to 2025. There’s more on that in About.

Details

Clicking a row on the home page morphs its number and title into the header of the next page, in browsers that support view transitions between pages. Other browsers load the page normally.

If you’ve asked your device to reduce motion, the water becomes a still pattern and nothing animates. The pages also read fine with JavaScript turned off. The source is on GitHub.
